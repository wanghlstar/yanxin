# 雁信 0.1.5（完结版本）

> 本仓库因上游更换仓库而停止维护，**0.1.5 为完结版本**。后续开发跟随上游在新仓库进行。
> 本文汇总 0.1.5 全部能力；历史提交已整理为单一初始提交。

## 邮件收取与账号

- 多账号 IMAP / POP3 收件、SMTP 发件；统一收件箱、账号独立视图与服务器文件夹树。
- IMAP IDLE 实时监听，期间周期性 NOOP 补查，服务器不主动推也能及时发现新邮件；另有定时补查作为兜底。
- 收件箱新实时通知可安全中断同账号的只读历史 FETCH：中断响应整体丢弃，不发布部分原件，并退出整个旧连接。
- 服务器文件夹新建/删除同步 IMAP；文件夹保存范围可按账号选择，读取前清点数量、体积与磁盘可用空间。
- 新邮件与发送结果系统通知，可分别开关。

## 阅读、对话与搜索

- 单封邮件独立阅读；有回复引用关系的邮件按往来对话展示，支持「按对话分组 / 逐封邮件」两种列表并可记忆选择。
- 邮件列表按日期对应的实际时间倒序，不直接比较带不同时区的日期字符串；时间相同时稳定排序，未知时间置后。
- SQL 固定页（cursor / revision）分页：「加载更多」不再重拉全前缀，解除 5000 条累计上限；远距离上一封/下一封通过阅读锚点直查邻居，不重载列表。
- 同范围同版本的后台刷新只更新首屏与元信息，保留已加载尾页与尾部游标。
- FTS5（trigram）候选索引 + 字面确认：5 万封规模检索从全量 JSON 扫描降为索引命中；短词与 NUL 等不可完整索引的记录精确回退，不改字符适配索引，也不执行 MATCH 布尔语法。
- 列表筛选：未读、星标、附件、搜索字段与日期范围（Calendar + Popover）集中在搜索框旁的筛选弹层；日期按本机日历加一天形成排他上限，覆盖 DST。

## 写信

- 富文本与纯文本正文，完整写信新草稿默认富文本，恢复旧草稿保留原格式。
- 正文默认仿宋 14pt，随发送的 HTML 一并带给收件方（div 内联包裹，兼容 Outlook）。
- 中文字体（宋体/楷体/黑体/仿宋/微软雅黑）与常用英文字体 + pt 字号，保存完整 CSS family 与回退链；不自动下载或嵌入字体文件。
- 问候语并入正文第一行（可编辑、字体随设置）并顶格，下方正文段首行缩进 2 字，形成「问候语/正文/落款」三段式。
- 正文内嵌图片：粘贴、拖放、工具条按钮三种方式；限长边 1600px，PNG 保锐利、JPEG 压体积；使用草稿自有内容快照与既有 cid MIME 入口，不依赖源文件或云上传；未准备完成不能发送或关闭。
- 每账号签名管理（HTML/图片、编辑与实时预览、启用开关与账号选择），草稿保存签名快照，切换发件身份重新核对签名与 SMTP 身份。
- 附件：选择去重、转发带入原附件（按完整 MIME 快照散列核对后复制为草稿归属文件）并逐项勾选，准备租约与窗口生命周期绑定。
- 空白新邮件不自动保存，关闭时直接舍弃；关闭、发送/定时提交与自动保存按顺序处理，防止迟到保存重建已舍弃的草稿。
- 回复默认不附原文，转发默认附原文，可手动调整；支持发送预览与本机定时发送。

## 本地存档

- 完整原始 MIME 作为存档原件独立留存，附件保留原始字节；解析/显示修复只改派生索引，不改写原件、原日期、邮件 ID、标记、分类及来源。
- 存档位置可配置并支持一键迁移；外置路径只迁完整原件，账号/索引/配置仍在本机，校验复制后再切换。
- 存档分层：外置存档根（冷库）+ 本地保留天数 + 随盘 index.html 索引；归档日志记录最近 50 条，首次查看自动回填既有存档，并显示外置实际存档总数。
- 存档树与本地文件夹视图按来源文件夹归组：服务器现存邮件归当前文件夹，服务器已删但存档保留的按原文件夹可见，被规则挪走的只跟目标文件夹。
- 全部/未读聚合视图与文件夹视图口径一致，包含服务器已删的本地存档；「全部收件箱」范围可按账号勾选，未配置时只算收件箱。
- 移除账号不自动删除已有存档，可在确认框中选择清除双根存档与关联数据。
- 存档备份/恢复与完整性校验集中在设置页同一张卡片。

## 过滤规则

- 按账号与多条件（发件人/收件人/主题/正文/有附件/邮件日期）配置，支持满足全部或任一条件、优先级排序、上移下移与命中后停止。
- 条件预览（不执行动作）后可对历史邮件执行。
- 本地归类保留原件；服务器复制/移动创建独立任务，通过任务队列串行执行并在执行记录中跟踪，结果未确认时不自动重发。
- 删除操作优先于已读/星标同步插队；彻底删除后本地列表即时隐藏，阅读中的邮件被删后前进到下一封（无则回空态）。

## OAuth（Google / Microsoft）

- Google 与 Microsoft 邮箱的浏览器授权 + PKCE + 本机回环收码，令牌存入钥匙串；支持 Gmail、Outlook、Microsoft 365。
- 回环 redirect_uri 使用无路径形式，兼容 Microsoft 任意端口回环；回调按 state 防伪造校验。
- client 配置只在原生发布构建注入（`MAIL_GOOGLE_CLIENT_ID` / `MAIL_GOOGLE_CLIENT_SECRET` / `MAIL_MICROSOFT_CLIENT_ID`，secrets 缺失即构建失败），不进入前端资源；账号高级配置仍可手填自己的 Client ID。

> 注：Gmail 的 IMAP/SMTP 端点在国内网络不可直达，需系统级 VPN（TUN 模式）环境方可收发；Microsoft 端点直连可用。

## 界面与桌面集成

- 全部界面组件统一使用 shadcn/ui；设置页按内容分组，同组卡片 24px 间距，不同组用 Separator 区分。
- 设置页：账号卡按数量自适应；存档统计/路径/管理共用一张卡片；系统通知与后台检查、签名、全部收件箱范围、外观、诊断折叠区、关于与更新的顺序与默认折叠状态已定型。
- 外观：侧栏字号可调（立即生效）；过滤规则与通讯录页布局紧凑化。
- Dock 图标开关：**开启时始终显示**，即便窗口关闭或最小化；关闭时仅在打开窗口时显示，最小化或关闭窗口后隐藏，菜单栏图标仍可打开主窗口；重启后保持选择。
- 侧栏：主导航组折叠箭头（状态持久化）、自定义细滚动条、未读徽标、本地存档账号组默认折叠。
- 外部 `.eml` 通过系统「打开方式」进入只读阅读，复用 MIME 解析与安全正文渲染，不自动导入账号或存档。
- 开机自启、新邮件通知、应用内更新（说明按 Markdown 渲染，外链经系统浏览器打开）。

## 构建与签名

- 构建默认使用本机固定签名身份 `Yanxin Local Code Signing`，钥匙串授权跨编译保持有效，不再回退 ad-hoc 签名。
- 应用存储与钥匙串标识保持 `dev.maildesk.desktop`，升级不丢失已有账号与本地存档。
