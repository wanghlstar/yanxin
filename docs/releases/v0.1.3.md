# 雁信 0.1.3（本地存储增强 Fork 版）

基于官方 0.1.2 的本地存储层增强构建，协议与同步逻辑与官方一致。

## 新增

- **存档位置可配置**：数据根目录支持环境变量 `YANXIN_DATA_DIR` 或配置文件 `~/.config/yanxin/data-dir`（支持 `~` 展开），默认可执行文件数据目录。设置页显示实际生效路径。
- **按账号/目录存档**：本地存档布局为 `archive/<账号邮箱>/<服务器文件夹(按 / 分层)>/<sha256>.eml`，可直接在访达中按账号和文件夹浏览；相对路径记录于消息数据 `relPath` 字段。

## 兼容与行为

- 旧版本存档（无 `relPath`）自动按原平面布局寻址，升级无需迁移。
- 同一内容被多个账号/文件夹收到时各存一份，删除某个账号的本地存档不影响其他账号副本。
- 清理暂存目录镜像相对路径；升级前中断遗留的平面暂存文件仍可正常恢复。
- 应用内备份仍为平面快照格式，恢复时按账号/文件夹重新落盘。

## 已知

- 更新端点与签名密钥为本 Fork 自有，与官方仓库互不干扰。
