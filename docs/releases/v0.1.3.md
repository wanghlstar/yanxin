# 雁信 0.1.3（本地存储增强 Fork 版）

版本号固定 0.1.3，后续改动通过重新指向 v0.1.3 tag 构建。

## 存档与位置

- 存档位置可在设置页更改：选择空目录时可一键迁移（含账号/规则/存档），也可选择删除或保留旧数据；目标已有数据则直接切换。
- 存档按 `账号/服务器文件夹/<hash>.eml` 布局，访达可直接浏览；旧数据自动兼容。
- 服务器移动邮件后，本地存档文件同步搬迁，磁盘/界面/服务器三方一致。
- 读取支持多存档根（内部/外置）顺序解析，为分层存档预留。

## 界面

- 侧边栏「保存在这台 Mac」下新增本地存档树：按账号 → 服务器文件夹分组展示已存档数，点击过滤。
- 侧边栏字号可调（紧凑/标准/大），立即生效；侧边栏整体密度收紧。
- 账号行点击即折叠/展开服务器文件夹；文件夹加载中仅在尚无数据时显示骨架屏。
- 邮件列表支持 ⌘A 全选、Shift+点击范围选择、右键菜单（标记已读/未读、保存到本地、归类、废纸篓）。
- 修复文本选中后对比度丢失（::selection 增加文字色）。

## 规则

- 合入官方修复：`正文` 条件的规则不再匹配未完整存档或正文片段解码失败的邮件。

## 测试

- Rust 235 项、前端 167 项全部通过（上游分页用例存在偶发失败，重跑即可）。
